# Ramazan Toz — Akıllı Berber Randevu ve Planlama PWA 💈

Mobil öncelikli, sesli Türkçe asistanlı, çakışma önleyici ve offline (PWA) destekli berber randevu yönetim web uygulaması.

## 🚀 Özellikler
- **Sesle Randevu Oluşturma:** Web Speech API destekli doğal Türkçe sesli komut algılama.
- **Akıllı Çakışma Motoru:** Çakışan saatleri otomatik tespit eder, kullanıcı onayı olmadan kaydetmez.
- **Mobil Öncelikli & PWA:** Telefona "Ana Ekrana Ekle" ile indirilebilir, internetsiz (offline) çalışabilir.
- **WhatsApp Entegrasyonu:** Tek tıkla müşteriye randevu onay mesajı hazırlama.
- **İstatistik & Özet:** Günlük ciro, randevu sayısı ve durum filtreleme.
- **Sıfır Bağımlılık:** Tailwind CSS CDN ve Vanilla JavaScript. Ek veritabanı veya backend gerektirmez, tüm veriler tarayıcıda (`localStorage`) saklanır.

## 📦 Kurulum ve Canlıya Alma
Bu proje statik bir web uygulamasıdır. Herhangi bir derleme (build) adımı gerektirmez:
- **Vercel:** Repoyu doğrudan import edin (`Framework Preset: Other`, root directory: `/`).
- **Doğrudan Tarayıcı:** `index.html` dosyasını açmanız yeterlidir.
